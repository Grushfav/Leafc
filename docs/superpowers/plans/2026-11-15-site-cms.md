# Site CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship draft → preview → publish CMS for marketing pages, experts, nav, and footer, with grantable `site_content_editor` access.

**Architecture:** JSON page documents + global experts/nav/footer resources in Neon via Drizzle; Express public/admin routes; Next static export client-fetches published content with hardcoded fallbacks; dashboard hybrid editors with toasts.

**Tech Stack:** Express 5, Drizzle/Neon, Next.js 16, React 19, Tailwind v4, multer uploads, hand-rolled validators (no new Zod dependency unless already present).

## Global Constraints

- Follow [docs/superpowers/specs/2026-11-15-site-cms-design.md](../specs/2026-11-15-site-cms-design.md)
- Effective editor = `role === "admin"` OR `site_content_editor === true`
- Publish is atomic per resource; public reads published only
- Division pages migrate into `cms_pages` with a `divisionLayout` section wrapping existing `DivisionPageContent` shape
- Do not redesign public visuals; make copy/media data-driven
- No commits unless the user asks
